# Таблицы Charge Exchange + Dirac: формат и нормировка

Версия выходного формата — **CCPACK01 / 1**. Рабочая область этого набора:
Zp = 29–92, E = 30–2000 МэВ/u, N = 0…27. N — число **связанных электронов
снаряда**, q = Zp − N. Zt — атомный номер элемента мишени. Между Z и N
интерполяции нет. В смеси используются концентрации атомов её элементов.

## 1. Исходные данные

| Источник | Содержимое и единицы |
|---|---|
| **ATIMA 1.41**, `splines_gz_1.41.tar` | Внутри gzip-файлы `Cu63-Si.dat.gz` и аналогичные. Заголовок задаёт Zp, опорную массу снаряда в u, состав мишени, её молярную массу, средний потенциал ионизации и плотность. Первый блок содержит B-сплайн пробега R(E), мг/см². Записанный порядок 5 означает степень 4. Следующие блоки содержат другие интегральные характеристики и здесь не используются. |
| **GLOBAL**, CSV | `Zp,Ap,Zt,At,E_MeV_u,Qe_in,Qe_out,dQe,kind,sigma_cm2,GLOBAL_E_MeV_u,source_run`. `Qe_in/out` — входное/выходное **N**, а не электрический заряд; `dQe=N_out−N_in`. `capture` увеличивает N, `loss` уменьшает. `sigma_cm2` — сечение на атом мишени, см². На узел имеется 106 переходов ΔN = ±1, ±2 между состояниями 0…27. `Ap,At` — массовые параметры источника. |
| **Dirac**, ZIP с NPZ | Общая сетка, канонические сечения голых ядер и поправки для отдельных N; подробности ниже. |
| **Tabulated SS**, отдельный каталог | Не участвует в создании dE/dx. `tables.index.tsv` перечисляет имя `.eltb`, Zp, Ap, Zt, At. `.eltb` имеет magic `G4ELT001`, заголовок 256 байт, сетки энергии/угла, полное сечение, R и CDF. Поиск физики выполняется по Zp,Zt; A — опорная метаданная. Текущий набор: Zp=26…82, Zt=14, 10–5000 МэВ/u. |

В данном GLOBAL представлены Zt=1…84 и 88…96; отсутствующие элементы не
восстанавливаются искусственно. Для точки с меткой E=30 расчёт GLOBAL
выполнен при 30,1 МэВ/u: обе координаты сохраняются. Сетка GLOBAL содержит
неокруглённые промежуточные энергии, поэтому перед нормировкой сечения
интерполируются, а равновесные вероятности рассчитываются заново.

В архиве Dirac используются:

- `grid.npz`: `E_u_MeV_u` — 39 энергий float64; `offsets` — 40 границ;
  `T_eV` — объединённые сетки кинетической энергии δ-электрона в эВ.
- `bare_Z{Z}.npz`: `D0_cm2_per_eV` — сечение на один электрон мишени;
  `valid_energy`, массивы численной погрешности.
- `Z{Z}_N{N}.npz`: `delta_Z` float32; `valid_energy`,
  `numerical_error_abs`, `R_num_error_rel`.
  Файлы `bare_Z…` и `Z…_N…` имеют маркер
  `table_schema=delta-with-canonical-D0-v1`; в `grid.npz` этого поля нет.

Срез энергии i задаётся `[offsets[i]:offsets[i+1]]`. Конвертер проверяет
маски и восстанавливает в float64
`D_N = D0 * (1−delta_Z/Zp)^2`. Отрицательные `delta_Z` сохраняются.
В выходном формате хранятся полные D_N, **Q_delta не используется**.
Переход от см²/эВ к см²/МэВ: умножение D на 10⁶; T — на 10⁻⁶.

Прямые расчёты имеются до Nmax=10 при Zp≤50 и до Nmax=15 при Zp>50.
Для остальных N≤27 применяется техническое продолжение
`D_N = D_Nmax * ((Zp−N)/(Zp−Nmax))²`. Оно не ограничивает состояния GLOBAL.

## 2. Как получается торможение

Из производной первого сплайна ATIMA:

`S_mass(E) = 1000 * m_ref_u / R′(E)`  [МэВ·см²/г],

`eps_ATIMA,t = (A_t / N_A) * S_mass`  [МэВ·см² на атом],

где A_t — молярная масса мишени из ATIMA; N_A=6,02214076×10²³ моль⁻¹.
Для выбранного элемента t строится генератор переходов GLOBAL K и решается
`p K=0, sum(p)=1` по всем N=0…27. Затем

`h_t,N = Zt * integral(T * D_N(T), T0…Tmax)`,

`B_t = (eps_ATIMA,t − sum_N p_N*h_t,N) / sum_N p_N*(Zp−N)²`,

`eps_full,t,N = B_t*(Zp−N)² + h_t,N`.

Все три величины B, h, eps имеют единицы МэВ·см². Плотность вещества в них
не входит. В транспорте `dE/dx = sum_t n_t*eps_full,t,N` [МэВ/см], где n_t
— число атомов элемента в см³. Для явных электронов выше порога Tcut из
этого полного торможения вычитается `sum_t n_t*Zt*M1(Tcut)`.

T0=0,001 МэВ. Данные ниже T0 отсутствуют. В Dirac принята кинематика
`gamma=1+E/931.494`, `Tmax=2*0.51099895*(gamma²−1)` [МэВ]. Энергетическая
координата ATIMA — энергия на атомную единицу массы. Формат сохраняет
конвенции источников; отождествление этой координаты с точным T/A конкретного
изотопа и поправка на конечную массу при подключении к Geant4 должны быть
заданы явно.

## 3. Подготовленные файлы

`manifest.json` содержит покрытие, правила интерполяции, параметры конвертации,
перечень входных и выходных файлов. Файлы разбиты по Zp:

| Файл | Массивы; порядок осей |
|---|---|
| `delta/Z029.ccbin` | `energy_MeV_u[E]`, `offsets[E+1]`, `T_MeV[P]`; `D_cm2_MeV[Ncalc,P]`; `tail0_cm2`, `tail1_MeV_cm2`, `tail2_MeV2_cm2` той же формы. P объединяет все сетки T. Ncalc=Nmax+1; продолжение до N=27 задаётся формулой выше. |
| `global/Z029.ccbin` | `energy_MeV_u[E]`, `calc_energy_MeV_u[E]`, `target_Z[t]`, `target_mass_g_mol[t]`, `transitions_N[106,2]`, `sigma_cm2[t,E,106]`. Сохраняется собственная энергетическая сетка GLOBAL. |
| `stopping/Z029.ccbin` | `target_Z[t]`, `target_mass_g_mol[t]`, `offsets[t+1]`; `energy_MeV_u[P]` — объединённые уточнённые сетки отдельных мишеней; `atima_MeV_cm2[P]`, `B_MeV_cm2[P]` и их левые пределы `atima_left_MeV_cm2`, `B_left_MeV_cm2`; `q2_eq[P]`, `H_eq_MeV_cm2[P]`; `p_eq[P,28]`, `S_full_MeV_cm2[P,28]`. |

В `stopping` срез мишени i задаётся `offsets[i]:offsets[i+1]`. У каждой
мишени своя сетка от 30 до 2000; это сохраняет все её узлы разрыва ATIMA
без раздувания общей сетки для остальных элементов. P в разных типах файлов
обозначает независимое число объединённых узлов.

`tailk(T)=integral_T^Tmax t^k D(t) dt`. Это **ненормированные** хвостовые
интегралы. Например, CDF выше Tcut равна `1−tail0(T)/tail0(Tcut)`.
Ncalc-сечения, частота события и вычитание жёстких потерь используют одни
и те же интегралы. Дополнительные множители Mott, screening или q² поверх
записанного D не применяются.

Между узлами T используется степенная функция, линейная в log(T),log(D).
Между энергиями смешиваются два соседних спектра с весом, линейным по log(E),
после отображения их поддержек на `u=(T−T0)/(Tmax(E)−T0)` и с соответствующим
якобианом. GLOBAL интерполируется линейно в log(E),log(sigma). B интерполируется
линейно по log(E), **без логарифмирования B**: берётся правое значение нижнего
узла и левый предел верхнего. В точном узле берётся правое значение, включая
E=2000. Это сохраняет небольшие скачки производной исходного сплайна ATIMA;
интерполировать через такой скачок нельзя. В произвольной энергии полное
торможение собирается из B и тех же интерполированных первых моментов D;
независимая интерполяция `S_full` не является рабочим правилом. Сетка B
уточняется по погрешности равновесной нормировки к ATIMA, целевой допуск
10⁻⁴ = **0,01%**.

## 4. Бинарный контейнер

Все числа little-endian, массивы плотные, порядок осей C. Файл пригоден для
отображения в память. Заголовок 256 байт (`<8sIIIIQQ216s`): magic `CCPACK01`,
version=1, kind (1=delta, 2=global, 3=stopping), Zp, число массивов,
размер всей области заголовков, размер файла, 216 нулевых байт.
За ним следуют дескрипторы по 128 байт (`<64s4sI6Q8s`): имя ASCII[64],
тип ASCII[4] (`f8`, `i8`, `i4`), число осей, четыре размера uint64,
смещение данных uint64, длина данных uint64, 8 нулевых байт.
Неиспользованные размеры равны нулю. Начала массивов выровнены на 64 байта.

Таблица [`legacy_q2.csv`](../../data/legacy_q2.csv) содержит поля
`Zp,Zt,E_MeV_u,ATIMA_dEdx_eq_MeV_cm2_g,q_rms_eq,q2_eq,status`.
Legacy использует её для расчёта торможения при текущем заряде иона
([подключение](../../README.md#connect-legacy)).
Низкоэнергетический CSV действующего fallback содержит
`Zp,Zt,At_ref_g_mol,E_MeV_u,dEdx_MeV_cm2_g,dEdx_left_MeV_cm2_g` (последнее — левый предел).
Поле `At_ref_g_mol` берётся из заголовка исходного сплайна ATIMA.
Эти CSV и таблицы SS остаются отдельными наборами; конвертер Dirac их не
подменяет. Подготовка файлов сама по себе не подключает новую физику к Geant4.

В SS энергия хранится в МэВ/u, полное сечение `sigma_mb` — в миллибарнах
(1 мб = 10⁻²⁷ см²), угловая координата `x=sin²(theta_CM/2)` лежит в [0,1],
CDF безразмерна. Это отдельная физика рассеяния на ядрах мишени.

Для воспроизведения нужны Python 3.11+ и NumPy (см. `requirements.txt`):

```text
python convert.py --dirac DIRAC.zip --global-csv GLOBAL.csv --atima-splines splines_gz_1.41.tar --output prepared
python export_dirac_csv.py --source prepared --output runtime
```

Параметры `--z-min`, `--z-max` выбирают поддиапазон снарядов;
`--normalization-tolerance` задаёт допуск нормировки (по умолчанию 10⁻⁴).
`--resume` проверяет конфигурацию и сравнивает ранее сохранённые массивы с пересчитанными.
